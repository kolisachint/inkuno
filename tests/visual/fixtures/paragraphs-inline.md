# Inline styles

Plain text, then **bold**, then *italic*, then ***bold italic***, then ~~strike~~ and ==highlighted== text.

Inline `code span` with `backticks` and a link to [the Rust site](https://www.rust-lang.org) and a [link with *emphasis* inside](https://example.com/a_b_c).

A wiki link to [[Another note]] and one with an alias [[Target note|shown text]].

A bare URL https://example.com/path?q=1 and an email address someone@example.com.

A sentence with a footnote reference[^1] and a second one[^note].

Escaped characters: \*not italic\*, \`not code\`, \# not a heading, 2 \* 3 = 6, and a backslash \\ here.

Hard line break at the end of this line  
followed by the next line, which should start on a new line without a blank line in between.

A soft break at the end of this line
continues on the next source line and should join it in one paragraph.

Underscores_in_the_middle_of_words and snake_case_names stay literal.

[^1]: The first footnote.
[^note]: A named footnote with **bold** text.
