# Right panel audit (app vs v2 prototype)

Scope: states 03-panel-outline, 04-panel-comments, 05-panel-versions, 06-panel-assistant (light; dark checked for 04 and 06), 22-compare-version (proto only; app compare checked via code and W5-08 log), 36 review-pending pill and 37 comment draft (proto only; app checked via code), W5 workflow shots.

Caveats:
- App shots use the note "Mixed: a week of project notes", the prototype uses "Week plan". Content-dependent states (comment cards, version rows) were compared with the W5 workflow shots (W5-04 card) and by code.
- Panel width is 280 px in both (`PANEL_W`, `nav.rs:60`; v2 `.rpanel{width:280px}`). Outline row 28 px and indent 12 px per level match (`nav.rs:55-57`; v2 `.ol`).
- `ui` scale is `prefs.size / 15`, so px tokens are 1:1 at the default size (`theme.rs:702`).
- Inline Accept/Reject pills and the comment draft card do not exist in the app. Both are design divergences, so they are listed as behaviour.

## v3 candidates (app better than v2, or v2 looks wrong)

- Outline fold chevrons (RP-09): keep. v2 has no collapsing; the app's fold is useful for long notes.
- Assistant model (RP-25): v2 copy says "pending changes", but the app writes review findings as comments. v2 should follow the app's model, or the app should change. Decide which.
- Block-form pending washes and no inline pills (RP-28, RP-29): `app-ui.md` §17 is the app's stated design. v2 inline pills and pill-buttons conflict with it. Decide whether v2 is updated to block form, or the app adds pills.
- Versions list (RP-21): the app's full timestamp to the minute is more exact than v2's relative "Today, 15:42". Either is fine; pick one.
- Band over the right dock (RP-04): v2 puts the switcher at the panel top with no band. The app keeps the band across the dock. Decide. The app's version keeps window-level consistency.
- Empty state for versions ("No version yet. Save one with Ctrl+Alt+S.", W5-06): helpful, not in v2. Keep.
- Comment anchoring (RP-19): the app's whole-line behaviour may be intended. Confirm before aligning v2 to selection-only.
- Comment card author and time (RP-11): the app stores no author or time in the card. Keep v2 only if the markup carries author and time.
- Note text size: `theme.rs` says "1 at 16" while the code uses `prefs.size / 15`. The comment is wrong or the constant is.
