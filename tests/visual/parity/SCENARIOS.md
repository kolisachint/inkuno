# Workflow scenarios (shared by app and prototype drivers)
Each step: perform the action, wait, screenshot `<scenario>-<step>.png`, note what happened.
Step names must be identical on both sides so they pair up.

W1 first-note: 01 start (empty/welcome or empty pane) · 02 new note (Ctrl+N or "New note") · 03 type "# Groceries" Enter "- [ ] milk" Enter "- [ ] eggs" · 04 click elsewhere so lines render · 05 toggle the first task box by click · 06 the note in the sidebar tree
W2 navigate: 01 Ctrl+P palette open · 02 type "road" · 03 Enter opens Roadmap · 04 single-click another sidebar note (preview tab, italic) · 05 double-click it (pinned tab) · 06 Ctrl+W closes tab · 07 Ctrl+Shift+T reopens
W3 format: 01 select a word (double-click) shows selection toolbar · 02 Bold via toolbar or Ctrl+B-equivalent shown in toolbar · 03 slash menu "/" on a new line · 04 pick "Table" or "Code" from slash menu · 05 click a rendered line reveals its Markdown
W4 split: 01 Ctrl+\ split right · 02 open another note in right pane · 03 Ctrl+1 focus left (other pane tabs dimmed) · 04 close split
W5 right-panel: 01 Ctrl+Shift+O outline · 02 click an outline entry (scroll) · 03 comments view (Ctrl+Alt+2) · 04 add a comment on a selection (selection toolbar Comment) · 05 resolve it · 06 versions view (Ctrl+Alt+3) · 07 save a version with a name (Ctrl+Alt+S) · 08 compare with a version · 09 assistant view (Ctrl+Alt+4)
W6 files: 01 right-click a sidebar note (context menu) · 02 Rename · 03 type new name Enter · 04 New folder · 05 Move to trash (toast with Undo) · 06 Scratch section: new scratch note
W7 chrome: 01 Ctrl+B hide sidebar · 02 Ctrl+Shift+S hide title bar (12px strip) · 03 hover strip (bar slides back) · 04 F9 focus mode · 05 Esc leave focus
W8 settings: 01 open Settings (palette "> settings" or sidebar Settings) · 02 Appearance: switch to Dark · 03 Editor page · 04 Shortcuts page (F1) · 05 change a setting toggle · 06 close settings back to note
