# Updates

Inkuno never checks for a new version and never downloads anything: there is no update banner, no background check, and no network request. When you want a newer version, fetch it yourself, the same way you installed the app.

## Upgrading

Follow [Upgrading](install.md#upgrading): download the new release from the [releases page](https://github.com/kolisachint/inkuno/releases/latest) and install it over the old one, or update through your package manager.

Your notes live in the vault, outside the app, so installing a new version never touches them.

## Privacy

Since nothing is ever checked or downloaded from inside the app, Inkuno makes no network request at all.
